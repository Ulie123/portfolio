# ulie123.github.io — Portfolio

Single-page portfolio. No build step, no dependencies.

## Files
- `index.html` — the whole site (HTML + CSS + JS inline)
- `Uli_Stechler_Resume.pdf` — linked from the nav, hero and footer

## Deploy to GitHub Pages
1. Create a new repo (e.g. `portfolio`, or `ulie123.github.io` to serve it at the root domain).
2. Drop `index.html` and `Uli_Stechler_Resume.pdf` in the root and push.
3. Repo → Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `root` → Save.
4. Live at `https://ulie123.github.io/<repo>/` (or `https://ulie123.github.io/` if you named the repo `ulie123.github.io`).

## Updating the resume
Replace `Uli_Stechler_Resume.pdf` with a file of the same name — all three links keep working.
